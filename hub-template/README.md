# Fathom shared bases

This folder is a ready-made list of shared bases for the Base Hub tab.

## Put it on GitHub

1. Go to https://github.com/new and sign in.
2. Repository name: `fathom-bases`. Choose **Public**. Click **Create repository**.
3. On the new page click **uploading an existing file**.
4. Drag everything inside this folder (`index.json`, `bases`, `README.md`) into the page.
5. Click **Commit changes**.
6. In the menu, open Base Hub > Shared. The address it reads is
   `https://raw.githubusercontent.com/YOUR-NAME/fathom-bases/main/index.json`
   (replace YOUR-NAME with your GitHub name).

## Add a base

1. In the game, save a base with Base Hub > My bases > Save nearby base.
2. Upload the saved file into the `bases` folder on GitHub.
3. Edit `index.json` and add an entry with the name, your name, the piece count and the file path.
